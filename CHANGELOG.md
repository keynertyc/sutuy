# Changelog

## 1.0.0

- Establish the documented public API and version-1 fixture compatibility as stable
  throughout 1.x, following Semantic Versioning.
- Keep the runtime API and behavior from 0.1.0 unchanged; existing code and fixtures
  need no migration.
- Improve English and Spanish introductions with live npm/CI badges, use cases,
  verification details, and the compatibility policy.
- Update the release guide for subsequent manual releases.

## 0.1.0

- Versioned byte-exact fixtures and pull-driven WHATWG stream replay.
- Deterministic partition exploration with UTF-8 and framing targets.
- Assertion-based checking and bounded failure-preserving cut reduction.
- Explicit baseline failures, deadlines, cancellation, and stability checks.
- SSE/NDJSON builders, runnable examples, and English/Spanish introductions.
